# Mon cahier à gommettes

Un cahier de vacances de CP à jouer sur téléphone, tablette ou ordinateur :
sons, syllabes, mots et phrases en lecture ; nombres jusqu'à 10, calculs et
maisons des nombres en maths. Chaque jeu rapporte des gommettes, et toutes les
3 gommettes une nouvelle image se colle dans l'album.

**Jouer :** https://michaeljhns88-hue.github.io/cahier-gomettes/

## L'installer sur un téléphone ou une tablette

Ouvrir le lien ci-dessus, puis :

- **Android (Chrome)** : bouton « Installer sur l'écran d'accueil » en bas de
  l'accueil du cahier, ou menu ⋮ → « Installer l'application ».
- **iPhone / iPad (Safari)** : bouton Partager → « Sur l'écran d'accueil ».

L'icône Gommettes apparaît avec les autres applis. Le cahier s'ouvre alors en
plein écran et marche aussi sans internet, une fois ouvert une première fois.

La progression (gommettes, album, chronos) est gardée sur l'appareil.

## Les fichiers

| Fichier | Rôle |
|---|---|
| `index.html` | Tout le cahier : jeux, styles et sons. |
| `manifest.webmanifest` | Nom, couleurs et icônes de l'appli installée. |
| `sw.js` | La copie hors connexion. Changer `VERSION` à chaque mise à jour. |
| `icons/` | Les icônes (Pastille, la gommette du cahier). |
