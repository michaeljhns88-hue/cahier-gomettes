# Mon cahier à gommettes

Un cahier de vacances de CP à jouer sur téléphone, tablette ou ordinateur :
sons, syllabes, mots et phrases en lecture ; nombres jusqu'à 10, calculs et
maisons des nombres en maths. Chaque jeu rapporte des gommettes, et toutes les
3 gommettes une nouvelle image se colle dans l'album.

**Jouer :** https://michaeljhns88-hue.github.io/cahier-gomettes/

Rien à installer : tout le jeu tient dans `index.html`. La progression
(gommettes, album, chronos) est gardée dans le navigateur de l'appareil.
